Experimento recomendado

Lab: Privilege Escalation & File Write Chains in Zammad & FortiMail

Objetivo: Reproduce two CISA‑tracked vulnerabilities (Zammad LPE and FortiMail path traversal) in isolated VMs to practice detection, exploitation, and mitigation.

Pré-requisitos

  • VirtualBox or VMware Workstation
  • Ubuntu 22.04 host with virtualization enabled
  • Docker (optional, for container tests)

Passos

  1. 1. Spin up two VMs: Zammad (latest stable) and FortiMail (trial image).
  2. 2. Update both to the latest patches to confirm vendor fixes.
  3. 3. For Zammad: enable debug logging, create a low‑privilege zammad user, and run a script that attempts to abuse the improper privilege management (e.g., set‑uid binary). Capture logs showing root access.
  4. 4. For FortiMail: craft a malicious HTTP request with path traversal and NULL‑byte to write a test file to /var/www/html/. Use curl with encoded payloads.
  5. 5. Verify file creation and execute the file to confirm RCE potential.
  6. 6. Document findings, create a remediation plan (input validation, principle of least privilege, patched versions).
  7. 7. Clean up VMs and export evidence (screenshots, logs, request/response) for portfolio.

Evidências esperadas

  • Zammad logs showing root‑level process execution from zammad user.
  • FortiMail filesystem listing confirming arbitrary file write.
  • Proof‑of‑concept request/responses and remediation checklist.

Condição de parada: All steps completed or 60 minutes elapsed, whichever comes first.
