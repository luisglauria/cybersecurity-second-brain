Five recent exploitable vulnerabilities were selected: file access in Atlassian products, command injection in Ahsay CBS, path traversal in Cisco Secure Email Gateway, reflected XSS in TanStack Router, and container sandbox bypass in Podman. Each offers concrete defensive learning opportunities for network, Linux, cloud, and secure coding practice.

Experimento recomendado

Detecção e mitigação de injeção de comando em endpoint simulado

Objetivo: Validar que validação de entrada e uso seguro de subprocessos impedem execução não autorizada de comandos do SO

Pré-requisitos

  • Docker Engine
  • Python 3.9+
  • curl ou httpie

Passos

  1. 1. Criar imagem Docker com um aplicativo Flask vulnerável que reproduz o comportamento do parâmetro 'random' do Ahsay CBS (executa subprocess.call(user_input, shell=True)).
  2. 2. Executar o container expondo a porta 5000.
  3. 3. Enviar requisição GET com payload '; id' no parâmetro random e observar a saída do comando 'id' nos logs do container.
  4. 4. Aplicar correção: substituir shell=True por lista de argumentos e validar que o entrada contém apenas alfanuméricos.
  5. 5. Reconstruir imagem, reiniciar container e repetir a mesma requisição maliciosa.
  6. 6. Verificar que nenhum comando externo é executado e que a aplicação retorna erro de validação.

Evidências esperadas

  • Logs do container mostrando execução do comando 'id' antes da correção.
  • Ausência de execução de comando externo e presença de mensagem de erro após a correção.

Condição de parada: Quando a mitigação for confirmada ou após 45 minutos de esforço.

Triagem

Descartados: Outros sinais foram descartados por serem menos recentes, duplicados em tema (ex.: múltiplos CVEs de Ahsay CBS) ou por não oferecerem aplicação prática imediata em laboratório defensivo.

Backlog

  • Análise de logs de seccomp para identificar tentativa de dessandboxing em Podman.
  • Implementação de regras de WAF para bloquear payloads de XSS refletido em TanStack Router.
Uso educacional e defensivo. Execute testes somente em ativos autorizados, laboratórios locais ou dados sintéticos.
