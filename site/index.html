Experimento recomendado

Path Traversal via CLI Commands in a Simulated Network Device

Objetivo: Demonstrate detection and mitigation of path traversal vulnerabilities in CLI-based administration interfaces.

Pré-requisitos

  • Docker installed
  • Linux container (e.g., Ubuntu)
  • Basic Linux file system knowledge
  • Ability to run a vulnerable Python script

Passos

  1. Pull a minimal Ubuntu container using `docker run -it ubuntu:latest /bin/bash`.
  2. Create a vulnerable script `vuln_cli.py` that executes `os.system('cat ' + user_path)` without sanitization.
  3. Run the script with a legitimate path such as `/etc/passwd` to verify it works.
  4. Attempt a path traversal payload like `../../../../etc/shadow` to confirm arbitrary file read.
  5. Implement mitigation by normalizing the path with `os.path.realpath` and checking the resolved path stays within an allowed directory.
  6. Re‑run the traversal payload to verify the mitigation blocks access.

Evidências esperadas

  • Script prints contents of `/etc/passwd` when given a valid path.
  • Traversal payload outputs `/etc/shadow` (or error) showing unauthorized access.
  • After mitigation, traversal payload returns 'access denied' and no file is read.

Condição de parada: When mitigation is verified and the script no longer allows arbitrary file access via path traversal, within 60 minutes.
