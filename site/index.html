Experimento recomendado

OpenSSH Authentication Bypass Lab

Objetivo: Demonstrate authentication bypass in SSH using crafted status code response

Pré-requisitos

  • Docker
  • Vulnerable OpenSSH container image
  • Network utility (e.g., netcat)

Passos

  1. Start a vulnerable OpenSSH container exposing port 2222
  2. From a separate host, send a malformed SSH handshake with unexpected status code to trigger bypass
  3. Observe successful login without password authentication
  4. Record the session and verify logs showing the unexpected status code

Evidências esperadas

  • Successful SSH session without valid credentials
  • Log entry indicating receipt of unexpected status code
  • Proof of concept captured in screenshots or logs

Condição de parada: Authentication bypass observed or 60 minutes elapsed

Triagem

Descartados: Attacking live production systems, unrelated vulnerabilities, non‑lab environments

Backlog

  • Cisco ASA DoS
  • Linux Kernel variable init chain
  • Adobe Commerce file upload
Uso educacional e defensivo. Execute testes somente em ativos autorizados, laboratórios locais ou dados sintéticos.
