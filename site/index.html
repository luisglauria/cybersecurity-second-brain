Experimento recomendado

Detecção e Correção de Path Traversal em API de Repositórios

Objetivo: Identificar e mitigar vulnerabilidade de path traversal em endpoint de API de commits de repositório

Pré-requisitos

  • Docker instalado
  • Conhecimento básico de Python/REST
  • Acesso a GitLab Community Edition

Passos

  1. 1. Executar GitLab CE em container Docker com configuração padrão
  2. 2. Criar repositório de teste e arquivo sensível fora do diretório esperado
  3. 3. Enviar requisição GET para /api/v4/projects/:id/repository/commits?path=../../../etc/passwd
  4. 4. Verificar se o sistema retorna conteúdo do arquivo alvo
  5. 5. Implementar validação de caminho absoluto e restringir acesso a diretórios permitidos
  6. 6. Reexecutar teste e confirmar bloqueio da tentativa

Evidências esperadas

  • Log de requisição bloqueada
  • Código patch com validação de caminho
  • Relatório de teste com resultados positivos

Condição de parada: Vulnerabilidade corrigida e testes automatizados confirmam proteção

Triagem

Descartados: Itens de GitHub Security Advisories descartados devido a falta de contexto prático imediato para laboratório local; vulnerabilidades MikroTik adicionais e Microsoft Windows mantidas no backlog por relevância secundária
