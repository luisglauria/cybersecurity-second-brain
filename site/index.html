Experimento recomendado

Defensive Testing: WordPress RFI Mitigation

Objetivo: Demonstrate secure coding practices to prevent CVE-2026-87902 exploitation

Pré-requisitos

  • Docker installed
  • WordPress Docker image
  • Basic PHP knowledge

Passos

  1. 1. Deploy vulnerable WordPress in Docker with default config
  2. 2. Create malicious .php file in /tmp/evil.php
  3. 3. Exploit via ?template=../../../tmp/evil to trigger RCE
  4. 4. Implement input validation: sanitize $_GET['template'] with basename() and realpath()
  5. 5. Add allowlist for valid template paths in wp-config.php

Evidências esperadas

  • Successful RCE before mitigation
  • Blocked exploitation after fix
  • Code diff showing validation logic
