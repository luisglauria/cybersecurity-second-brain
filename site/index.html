CISA Known Exploited Vulnerabilities · 2026-11-10 · Fonte direta

Experimento recomendado

Reproduce GPUStack unauthenticated admin access in a lab container

Objetivo: Demonstrate how missing authentication on GPUStack can be abused to gain administrative control and expose secrets.

Pré-requisitos

  • Docker installed
  • Git
  • Python 3
  • docker‑compose

Passos

  1. Clone GPUStack repo (git clone https://github.com/gpustack/gpustack.git)
  2. Build container image with docker build .
  3. Run container exposing port 8080
  4. Send POST /v2/inference‑backends/from‑yaml without authentication using curl or Python script
  5. Check for created admin API key and any secret leakage in logs
  6. Document findings and create a detection rule

Evidências esperadas

  • Admin API key printed in response or logs
  • Secrets (e.g., cloud provider keys) visible in container output
  • Successful creation of inference backend without auth

Condição de parada: Experiment stops when admin API key is created without authentication or after 5 minutes if no unauthorized access is achieved.
