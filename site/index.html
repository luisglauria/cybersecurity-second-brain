Experimento recomendado

Simulação de Path Traversal em Aplicação Web Local

Objetivo: Identificar e mitigar uma vulnerabilidade de path traversal usando uma aplicação web deliberadamente vulnerável.

Pré-requisitos

  • Docker instalado
  • Acesso a terminal Linux
  • Conhecimento básico de HTTP

Passos

  1. Baixar e executar o container DVWA (Damn Vulnerable Web Application) via Docker.
  2. Acessar a página de 'File Inclusion' no DVWA e tentar navegar para arquivos do sistema (ex: /etc/passwd).
  3. Documentar o payload usado e o resultado da exploração.
  4. Implementar uma validação de caminho em um script Python simples para bloquear tentativas de traversal.

Evidências esperadas

  • Captura de tela do arquivo /etc/passwd acessado via DVWA.
  • Código Python com função de sanitização de caminhos.

Condição de parada: Mitigação validada com payloads bloqueados no script Python.

Triagem

Descartados: Vulnerabilidades repetidas (Ahsay autenticação), CVEs antigos (Apache Struts, ProFTPD) e advisories de baixa relevância prática para estudo inicial.

Backlog

  • Estudar CVE-2026-0322 (Palo Alto PAN-OS) para análise de injeção de código em firewalls.
  • Avaliar GHSA-pw5q-rjx4-7f7p (Arcane) para testes de privilege escalation em APIs.
  • Praticar mitigações para deserialização insegura em aplicações Python.
Uso educacional e defensivo. Execute testes somente em ativos autorizados, laboratórios locais ou dados sintéticos.
