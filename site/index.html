Experimento recomendado

Lab: Exploit and Mitigate GitLab Path Traversal (CVE-2026-85706)

Objetivo: Demonstrate unauthenticated file read via path traversal in GitLab CE and implement input sanitization

Pré-requisitos

  • Docker installed
  • Internet access
  • GitLab CE Docker image (latest)
  • Basic Linux command line knowledge

Passos

  1. Pull and run GitLab CE container exposing port 80
  2. Access GitLab endpoint for repository uploads (e.g., /gitlab/api/v4/projects/1/repository/uploads)
  3. Send crafted request with ?path=../etc/passwd using curl
  4. Observe response containing /etc/passwd content
  5. Modify application or proxy to sanitize the path parameter
  6. Re‑send request and verify no file content is returned

Evidências esperadas

  • HTTP response with /etc/passwd file content when path traversal is used
  • No file content when sanitized path is used
  • Documentation of successful exploit and mitigation

Condição de parada: When successful exploit and mitigation are demonstrated within 45 minutes
