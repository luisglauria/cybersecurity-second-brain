Experimento recomendado

Detect AF_ALG socket race condition using eBPF tracing

Objetivo: Identify abnormal concurrent writes to AF_ALG sockets in a controlled environment and generate alerts via eBPF.

Pré-requisitos

  • Linux kernel 5.10+ with BPF support
  • bpftrace or bcc tools installed
  • A test program that opens AF_ALG sockets and performs concurrent writes (can be a simple C/Python script)

Passos

  1. 1. Compile and run the test program that spawns multiple threads writing to the same AF_ALG socket.
  2. 2. Attach an eBPF tracepoint to sock_alloc_send_skb or similar kernel function to count write operations per socket.
  3. 3. Log occurrences where write count exceeds a threshold within a short time window.
  4. 4. Correlate logs with test program timestamps to confirm race condition detection.
  5. 5. Optionally, apply a kernel patch or configure socket options to mitigate and observe reduced alerts.

Evidências esperadas

  • eBPF output showing spikes in write counts per AF_ALG socket during test execution
  • Correlation of spikes with the test program's concurrent write phases
  • Reduction or elimination of spikes after applying a mitigation (e.g., using socket locking or updated kernel)

Condição de parada: When consistent evidence of race condition is observed and mitigation verification is complete, or after 30 minutes of active tracing.
