Experimento recomendado

SSRF and Path Traversal Mitigation Lab

Objetivo: Simulate and mitigate SSRF/path traversal vulnerabilities in a controlled web app.

Pré-requisitos

  • Python 3.x
  • Docker
  • OWASP WebGoat or custom Flask app
  • Burp Suite or curl

Passos

  1. Deploy a vulnerable Flask app with SSRF and path traversal endpoints.
  2. Use curl/Burp to exploit SSRF to access internal services.
  3. Exploit path traversal to read/write files outside the web root.
  4. Implement input validation, URL allowlists, and sandboxing.
  5. Verify mitigations block exploitation attempts.

Evidências esperadas

  • Successful SSRF/path traversal exploitation in the lab.
  • Mitigated app blocks malicious requests.
  • Logs showing blocked attempts and sanitized inputs.

Condição de parada: All exploitation attempts are blocked by mitigations.

Triagem

Descartados: Low-severity GitHub advisories (virtualenv, filelock oplock) and non-chained vulnerabilities with limited practical impact for portfolio projects.

Backlog

  • Monitor CISA KEV updates for new entries.
  • Explore cloud-specific vulnerabilities in AWS/Azure IAM misconfigurations.
  • Investigate AI/ML model poisoning as a defensive threat vector.
Uso educacional e defensivo. Execute testes somente em ativos autorizados, laboratórios locais ou dados sintéticos.
