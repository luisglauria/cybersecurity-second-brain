Experimento recomendado

ReDoS Detection and Mitigation in wcmatch Library

Objetivo: Understand ReDoS vulnerability class, reproduce polynomial-time matching, and apply safe regex practices.

Pré-requisitos

  • Python 3.8+
  • pip install wcmatch==8.3 (vulnerable version)
  • Basic regex knowledge

Passos

  1. Install vulnerable wcmatch version in isolated virtual environment
  2. Craft a multi-star pattern (e.g., '**/*') and generate long input strings with repeated separators
  3. Measure execution time for increasing input lengths to observe polynomial growth
  4. Upgrade to patched version (>=8.4) or apply safe pattern alternatives
  5. Re-run test to verify linear time handling

Evidências esperadas

  • Execution time increases polynomially with input length on vulnerable version
  • Patched version handles same input in linear time
  • Documentation of regex pattern that caused ReDoS and mitigation applied

Condição de parada: If execution exceeds 10 seconds or system becomes unresponsive, terminate immediately.
