Experimento recomendado

Mitigação de Path Traversal em Aplicações Web

Objetivo: Demonstrar e corrigir vulnerabilidade de path traversal em ambiente controlado

Pré-requisitos

  • Docker instalado
  • Conhecimento básico de Linux
  • Acesso a terminal

Passos

  1. 1. Baixar e configurar instância Docker de aplicação web com path traversal (ex: DVWA ou WebGoat)
  2. 2. Identificar endpoint vulnerável via análise de código ou documentação
  3. 3. Executar ataque de path traversal para acessar arquivos fora do diretório raiz
  4. 4. Aplicar correção: validação de caminhos, uso de funções seguras de acesso a arquivos
  5. 5. Reexecutar ataque para verificar mitigação

Evidências esperadas

  • Log de tentativa de acesso a /etc/passwd
  • Arquivo corrompido após ataque
  • Mensagem de erro após correção
  • Teste bem-sucedido de acesso restrito

Condição de parada: Ataque bloqueado e acesso a arquivos sensíveis negado após implementação da correção

Triagem

Descartados: Itens com baixa aplicação prática (ex: DoS em BIND, buffer overflow em Citrix) ou vulnerabilidades em produtos end-of-life foram descartados para foco em casos ativos e corrigíveis
