CISA Known Exploited Vulnerabilities · 2026-09-08 · Fonte direta

Experimento recomendado

Reproduce GitLab Path Traversal CVE-2026-85706

Objetivo: Show that unauthenticated requests can read arbitrary repository files via the commits API

Pré-requisitos

  • GitLab CE Docker image
  • curl
  • network access

Passos

  1. Start GitLab CE container exposing port 8080
  2. Create a test project with a file path containing '..' characters
  3. Send GET request to /api/v4/projects/:id/repository/commits with malicious path parameter
  4. Observe response containing file contents without authentication

Evidências esperadas

  • HTTP 200 response with file listing
  • File content exposed without authentication

Condição de parada: When file content is successfully retrieved without authentication
