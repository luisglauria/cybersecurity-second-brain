Experimento recomendado

Simulação de Path Traversal em API Local

Objetivo: Detectar e mitigar uma vulnerabilidade de path traversal em uma API REST local.

Pré-requisitos

  • Docker
  • Python 3.9+
  • Burp Suite Community ou curl
  • Acesso a um repositório de código local

Passos

  1. Criar uma API Flask com endpoint /arquivo que lê arquivos via parâmetro 'caminho'.
  2. Injetar payloads como ../../../../etc/passwd para testar path traversal.
  3. Usar Burp Suite para interceptar e modificar requisições.
  4. Implementar sanitização de caminhos com os.path.basename e validação de diretório.
  5. Repetir testes para confirmar mitigação.

Evidências esperadas

  • Logs mostrando acesso a arquivos fora do diretório esperado antes da mitigação.
  • Código atualizado com validação de caminho e testes automatizados.

Condição de parada: A API rejeita payloads de path traversal e retorna apenas arquivos dentro do diretório permitido.

Triagem

Descartados: Vulnerabilidades em dispositivos de rede (MikroTik, Fortinet) e sistemas operacionais (Windows) foram descartadas por exigirem ambientes específicos. Avisos de baixa severidade (October CMS) e hype em correções de navegadores (Chromium V8) foram ignorados.

Backlog

Uso educacional e defensivo. Execute testes somente em ativos autorizados, laboratórios locais ou dados sintéticos.
