CISA Known Exploited Vulnerabilities · 2026-10-04 · Fonte direta

Experimento recomendado

Portable Struts RCE Lab

Objetivo: Demonstrate and mitigate command injection in a controlled environment

Pré-requisitos

  • Docker installed
  • Apache Struts source code available
  • Basic networking knowledge

Passos

  1. Clone Struts repository into a Docker container
  2. Enable Dynamic Method Invocation feature
  3. Send crafted request with method:prefix to trigger RCE
  4. Observe remote code execution
  5. Apply fix by disabling dynamic method invocation
  6. Verify mitigation prevents exploitation

Evidências esperadas

  • Successful shell command execution against the vulnerable endpoint
  • Prevention after disabling dynamic method invocation

Condição de parada: RCE is successfully blocked by configuration changes

Triagem

Descartados: Higher severity vulnerabilities like MikroTik RouterOS and Apple CoreGraphics require extensive setup beyond 60 minutes

Backlog

  • ONLYOFFICE Path Traversal
  • Fortinet FortiMail Path Traversal
  • Cisco Catalyst SD-WAN Manager
Uso educacional e defensivo. Execute testes somente em ativos autorizados, laboratórios locais ou dados sintéticos.
